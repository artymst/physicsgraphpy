# **PhysicsGraphPy**
*... beginner-friendly python library for visualizing kinematics motion graphs*

---

## **Overview**
**Physicsgraphpy** is a beginner-friendly Python library for simulating and visualizing motion in Physics. You can create kinematics or projectile scenarios, plot position/velocity/acceleration graphs, and animate motion with simple code.

This library is ideal for students, educators, and anyone exploring basic physics concepts programmatically. it’s licensed under **MIT** and available for manual installation via Github Releases or the official site.

---

## **Features**
**PhysicsGraphPy** includes tools for exploring a wide range of motion:

- **Simulate** free-fall, linear kinematics, and projectile trajectories  
- **Plot graphs** for position, velocity, and acceleration  
- **Animate motion** step by step  
- **Calculate** max height, time of flight, range, and more  
- **Export** data to CSV or Markdown  
- **Use unit tools** including SI checks and conversions  
- **Customize graph styles** for cleaner visuals and presentations  

---

## **Requirements**
To use the library, you’ll need:

- **Python 3.7 or higher**  
- **matplotlib**  
- **numpy**

No specialized software required, any standard Python setup works.

## **Supported systems**
**PhysicsGraphPy** runs on:

- **Windows**  
- **macOS**  
- **Linux**

As long as Python is supported, the library should work. browser-based or mobile interpreters may be limited.
